# Guía de pruebas

Este documento forma parte de una práctica académica de pruebas de software aplicada al repositorio `qa-practica-github`.

## Alcance

Se evaluarán comportamientos observables de GitHub mediante pruebas de sistema, aceptación y caja negra.

## Evidencias

Las capturas de pantalla y los resultados de ejecución se documentarán en el informe de la práctica. No se consideran ejecutadas las pruebas que únicamente estén planificadas.
